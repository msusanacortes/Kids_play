#Kids Video App 📺👧👦

*¡Bienvenido a Kids Video App! Este proyecto es mi segundo ejercicio práctico generado y refactorizado con la ayuda de Google Gemini.*

⚠️ Nota sobre el proyecto: Este desarrollo es un ejercicio base, casi bocetado. Su propósito principal es funcionar como un prototipo rápido o wireframe interactivo para experimentar con flujos de usuario, diseño de interfaces (UI) y generación de código asistida por IA, más que ser un producto final pulido para producción.

🎓 Contexto Académico

Este proyecto fue desarrollado como parte de la clase:

Curso: ID 2278 Vibe Coding, desarrollo de prototipos digitales con Inteligencia Artificial.

El objetivo de este proyecto fue crear la interfaz base de una aplicación de videos para niños (estilo plataforma de streaming), completamente funcional en el lado del cliente y empaquetada en un único archivo index.html para un despliegue ultra rápido en GitHub Pages.

🚀 Características Principales (Boceto Funcional)

Múltiples Perfiles: Pantalla de inicio para seleccionar quién está viendo (Leo, Mía, Hugo, Ana), cada uno con su propio historial y favoritos (datos simulados en memoria).

Puerta Parental (Parent Gate): Un candado de seguridad simple (basado en una multiplicación) para evitar que los niños accedan a la configuración.

Panel de Control (Dashboard): Zona exclusiva para padres donde se pueden agregar nuevos videos simulados al catálogo local.

Categorías Dinámicas: Filtrado rápido por "Todos", "Música", "Animación" y "Educativo".

Navegación Intuitiva: Botones grandes y coloridos con secciones de Inicio, Historial (Lo que has visto) y Favoritos.

Simulador de Reproductor: Un modal inmersivo que simula visualmente la reproducción de un video seleccionado.

🛠️ Tecnologías Utilizadas

Para mantener este prototipo simple y sin dependencias de Node.js o bundlers, se utilizaron las siguientes herramientas directamente desde un CDN:

React 18 (Vía CDN) - Para el manejo del estado y la interfaz de usuario.

Tailwind CSS (Vía script CDN) - Para el diseño responsivo, colores y estructura rápida.

Babel Standalone - Para compilar el código JSX directamente en el navegador.

SVG Icons - Íconos integrados en el código para no requerir librerías externas.
